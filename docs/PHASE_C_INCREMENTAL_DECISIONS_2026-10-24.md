## 1. 核心设计变更：恢复 Hand Made 八件工具的获取方式，但禁用其功能

此前的设计是：

- 禁用 Hand Made 原八件工具的合成配方；
- 在 JEI 和创造模式物品栏隐藏这些物品；
- 八件物品保留注册 ID，但无法通过正常生存流程获得；
- Tetra 八种升级材料暂时使用原木占位。

**上述方案全部撤销，改为以下正式方案。**

### 1.1 原版八件工具保留正常获取方式

八件 Hand Made 原版工具必须保留：

- 原始 Registry ID；
- 原始物品贴图和模型；
- 原始工作台合成配方；
- 正常物品栏、创造模式物品栏及 JEI 展示；
- 作为普通合成材料和 Tetra 升级材料的能力。

不需要刻意保留原来的特殊工具耐久、攻击加成、挖掘加成或附魔功能，但不能因调整这些属性而破坏 ID、贴图或合成兼容性。

**特别注意：不能重新注册同名物品代替原物品。** 必须兼容 Hand Made 原有注册系统和已存在存档。

原本为禁用配方、隐藏 JEI 或阻止物品获取所编写的代码，应在确认不再需要后移除或调整，不得与新规则冲突。

### 1.2 八件原版工具的全部原有功能必须失效

这八件物品现在仅作为普通合成与升级材料存在。

玩家直接手持原版 Hand Made 工具时，不允许再通过它们执行原有的特殊行为，包括：

| 工具 | 需要禁用的行为 |
|---|---|
| 冲压锤 | 手动冲压、蓄力攻击、额外暴击/击退、特殊工具耐久消耗 |
| 研钵 | 装载材料、手动研磨、研磨动画及其特殊行为 |
| 碾钵 | 装载材料、粉碎、研磨回退及相关特殊行为 |
| 搅拌杖 | 工作盆搅拌、特殊蓄力、手动加工 |
| 指杆 | 部署加工、特殊方块交互、工作方块高亮及其他原有专属行为 |
| 手锯 | 切削、连锁砍树、斧类特殊操作、额外挖掘效率等 |
| 风箱 | 鼓风加工、推动实体及其他气流效果 |
| 灌注枪 | 流体抽取、注入、源方块取放、相关特殊操作 |

玩家仍然可以像持有普通材料一样握持这些物品，并进行 Minecraft 通常允许的普通物品操作，但不得触发 Hand Made 特有加工或其他特殊效果。

这不意味着删除 Hand Made 的加工代码。

**八件工具的全部原有功能需要转移、适配到对应的 Tetra 特化头部上。**

因此必须区分：

- 原版 Hand Made 物品：特殊功能全部禁用；
- Tetra 特化头部：继承原版 Hand Made 对应的加工及非加工能力。

禁止因为禁用原物品而连带禁用 Tetra 特化头部依赖的共享加工逻辑、配方查询、流体处理或兼容接口。

### 1.3 技术实现方式

请参考 Forge 1.20.1 中 Disable Tools、Item Interaction Disabler 等 Mod 的实现思想，但**不要将这些第三方禁用 Mod 设置成新的必需依赖**。

优先在 CreateTetraHandcraft 内实现兼容性禁用层。

要求：

1. 核查 Hand Made v0.5.0-beta-1.20.1 实际源码与目标 JAR。
2. 枚举八件工具的所有功能入口，包含 `use`、`useOn`、持续使用、使用结束、方块事件、实体事件、左键和其他静态事件。
3. 使用必要的 Forge 事件与定向 Mixin 拦截原物品行为，保证客户端与服务端一致。
4. 不得只拦截普通右键。手锯的挖掘效率、连锁砍树，指杆和灌注枪的特殊事件等均需要独立检查。
5. 不要通过反射强制篡改物品 Registry，或者直接覆盖第三方 JAR。
6. 保留正常的配方输入识别、NBT 和数据包兼容性。
7. 检查来自可选模组、自动化实体及其他外部调用路径的功能绕过问题。
8. 原物品的特殊行为禁用不能妨碍 Tetra 适配层合法执行相同加工。
9. 对可能含有历史内部材料、液体或特殊状态的旧物品，制定不会复制资源或无提示丢失资源的兼容处理策略。

最终需要用真实游戏验证，而不只是静态检查事件处理器。

## 6. 必须保证科技树不存在循环依赖

新的整体目标是：

```text
Minecraft 原版资源
        ↓
Create 安山合金
        ↓
合成 Hand Made 原版工具
        ↓
制作对应 Tetra 原理图
        ↓
在 Tetra 工作台升级工具头部
        ↓
使用 Tetra 特化头部进行手工加工
        ↓
获得铁板、铜板、搅拌头等材料
        ↓
使用手工搅拌获得第一批黄铜
        ↓
制作黄铜机壳
        ↓
解锁七台 Create 机械
        ↓
制作动力合成器和粉碎轮
```

其中最关键的是**首批黄铜的获取**。

原版 Create 的加热黄铜混合配方依赖工作盆、热源和搅拌。现在机械搅拌器的合成需要黄铜机壳，不能让玩家必须先制作机械搅拌器才能获得第一批黄铜。

因此必须实现并实测：

1. 玩家在黄铜阶段之前能够合法获得三级锤及必要的 Tetra 工具。
2. 能够制作冲压锤原理图和冲压锤原版材料，获得 Tetra 冲压能力。
3. 能用 Tetra 冲压能力制造铁板、铜板。
4. 能制作 Create 搅拌头、工作盆、烈焰燃烧室等必要设施。
5. 能制作搅拌杖原版材料及搅拌杖原理图，获得 Tetra 搅拌能力。
6. 使用合法热源，在 Create 工作盆中通过 Tetra 搅拌能力完成原本的黄铜合成。
7. 获得第一批黄铜后，能够继续制造黄铜机壳和各台机械。
8. 其他原理图同样能够通过合法材料获取路线制得。

这里必须使用**已有的 Create / Hand Made 加工配方**。

不得为了打通科技树而擅自添加黄铜工作台合成配方、修改原有加工产物或添加新的手搓加工配方。

如果真实运行发现材料链阻断，先检查是特化能力没有正确执行、原版材料需要其他前置工序，还是第三方 Mod 兼容问题。记录最小失败复现，不自行发明新的工艺来绕过限制。
